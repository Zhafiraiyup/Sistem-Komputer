Apa itu Sistem Komputer?

Sistem komputer adalah sekumpulan komponen yang saling bekerja sama untuk menerima data, mengolah data, menyimpan data, dan menghasilkan informasi yang berguna bagi pengguna.

Hardware

Perangkat keras yang dapat dilihat dan disentuh secara fisik.

Software

Program atau perangkat lunak yang digunakan untuk menjalankan berbagai fungsi komputer.

Brainware

Manusia yang menggunakan atau mengoperasikan komputer.

🖥️ Hardware

Kenali berbagai perangkat keras berdasarkan fungsinya.

Input

Keyboard

Memasukkan teks, angka, dan perintah ke komputer.

Input

Mouse

Menggerakkan kursor dan memberikan perintah klik.

Process

CPU / RAM

Otak komputer untuk memproses data dan memori sementara.

Output

Monitor

Menampilkan hasil proses berupa visual/gambar.

Storage

SSD / HDD

Menyimpan data dan file secara permanen.
